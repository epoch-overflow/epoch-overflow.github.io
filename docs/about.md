# このサイトについて

## 目的

2038年問題は、2000年問題に比べるとあまり知られていません。特に日本語で読めるまとまった情報が少ないことから、このサイトでは2038年問題と、同じ種類の「時刻表現の桁あふれ」問題について、日本語で情報を整理しています。将来は英語版も用意する予定です。

## 誤りの報告・提案

内容の誤りの指摘、情報の提供、追加の提案は、[GitHub の Issue](https://github.com/epoch-overflow/epoch-overflow.github.io/issues) にお寄せください。Pull Request も歓迎します。
