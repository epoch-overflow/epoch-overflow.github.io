# 2038年問題と、時刻の桁あふれ問題

**2038年1月19日 12時14分07秒（日本時間）**を過ぎると、時刻を32ビットの符号付き整数で扱っているコンピュータは、日付を正しく扱えなくなります。これが **2038年問題** です。

2000年問題（Y2K）ほど知られてはいませんが、組込み機器や古いファイル形式、データベースなど、身の回りのさまざまな場所に原因が潜んでいる可能性があります。しかも、2038年になって初めて問題が起きるとは限りません。「30年後の満期日」のように**未来の日付を計算する処理**では、すでに影響が出ることがあります。

このサイトでは、2038年問題を中心に、GPSの週番号ロールオーバーなど**時刻表現の桁あふれ**が原因で起きる問題全般について、日本語で情報を整理しています。
