# GPS週番号ロールオーバー

!!! note "執筆中"
    このページは骨組みの段階です。

## 概要

GPS衛星が送る航法メッセージでは、日付を「**GPS時刻の起点（1980年1月6日）からの週番号**」と「週の中の経過秒数」で表します。従来の航法メッセージでは週番号が**10ビット**しかないため、1024週（約19.6年）ごとに週番号が0に戻ります。

| 回 | 日付（GPS時刻） |
|---|---|
| 1回目 | 1999-08-22 |
| 2回目 | 2019-04-07 |
| 3回目 | 2038-11-21 |

週番号が0に戻ったことを受信機が正しく扱えないと、日付が約19.6年前にずれて表示されたり、受信機が正しく動かなくなったりします。

## 2038年問題との関係

3回目のロールオーバーは2038年11月で、2038年問題（2038年1月）と同じ年に起きます。ただし、原因はまったく別の仕組みです。
