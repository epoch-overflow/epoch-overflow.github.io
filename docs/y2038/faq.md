# よくある質問

??? question "64ビットのパソコンなら関係ないのでは？"
    OS とCライブラリの `time_t` が64ビットなら、その部分は大丈夫です。ただし、アプリケーションが時刻を32ビットの変数やデータ形式に入れていると、問題は残ります。詳しくは[仕組み](mechanism.md#time-t-64bit)を参照してください。

??? question "2038年1月19日に一斉に何かが起きるのですか？"
    その瞬間に問題が表に出るシステムもあります。ただ、未来の日付を計算する処理では、それより前に症状が出ることがあります。逆に、32ビットの時刻を使っていても、その値を比較や計算に使っていなければ目立った症状が出ないこともあります。

??? question "日本時間だと何時ですか？"
    2038年1月19日 12時14分07秒（JST）が、表せる最後の時刻です。その1秒後に桁あふれが起きます。

??? question "Y2K38、Epochalypse とは？"
    どちらも2038年問題の別名です。Y2K38 は「Year 2038」の略記で、Epochalypse は epoch（エポック）と apocalypse（黙示録）を組み合わせた造語です。
