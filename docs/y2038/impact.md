## 影響を受けやすいもの

### 32ビットのOS・CPUを使う組込み機器

産業機器、医療機器、車載機器、ネットワーク機器、家電などは、一度設置されると10年、20年と使われ続けることが珍しくありません。今出荷されている機器が2038年にもまだ動いている可能性は十分にあります。

### ファイル形式・ファイルシステム

タイムスタンプを32ビットで記録するファイル形式やファイルシステムでは、OSが64ビット対応していても、記録できる日付に上限があります。

### データベース・データ形式

列の型や、シリアライズ形式（バイナリプロトコル、独自形式）で時刻を32ビット整数として持っている場合です。

### アプリケーションのコード

OS やライブラリが対応済みでも、アプリケーションが時刻を `int` に代入していたり、32ビット幅で保存していたりすると、問題が残ります。

## 関連する事例

時刻・日付を32ビット整数に詰め込んだことで起きた障害は、2038年問題以外にもあります。例えば2022年1月1日には、Microsoft Exchange Server のマルウェア対策エンジンで、更新バージョンを `2201010001`（22年01月01日00:01）のような整数として扱った結果、32ビット符号付き整数の上限（2,147,483,647）を超えて処理が止まる障害が起きました（いわゆる「Y2K22」）。
